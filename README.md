# Lesson 7 - Areas and Items

```
dotnet run
```

| File | What it is |
|---|---|
| `GameMechanics/Area.cs` | A place in the world. |
| `GameMechanics/Item.cs` | A thing in the world. |
| `GameMechanics/CreatureBuilder.cs` | Builds a `Creature` one part at a time, starting from a name. |
| `GameMechanics/StockEntities/StockCreatures.cs` | Six ready-made creatures, from a kobold to an ogre. |
| `GameMechanics/PlayerBuilder.cs` | Builds a `Player`, with strategies for the parts that get rolled. |
| `GameMechanics/StockEntities/StockPlayers.cs` | Bree and Tamsin. |
| `Rules/DiceRollStrategies.cs` | The ways to roll a set of dice. |
| `Display/CharacterSheet.cs` | Prints a sheet. |
| `Program.cs` | Builds the party and the goblin.  Keep it short. |
